Failed Indian Startups Analytics Dashboard

A Streamlit analytics app for exploring shutdowns, funding loss, sector patterns, correlations, regression models, and predictive what-if scenarios using startups.xlsx.

View app.py Read setup guide Download dataset

What Is Included

Dashboard KPIs Funding, shutdown counts, median years active, and top failed startups.
Sector Analysis Sector-level capital exposure, failure categories, and risk scoring.
Correlation Numeric heatmap and strongest metric relationships.
Prediction Regression models, feature importance, and what-if prediction inputs.

Run Locally

python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py

Deploy From GitHub

Upload all files in this folder to the root of your GitHub repository. For Streamlit Cloud, choose app.py as the main file.

GitHub Pages can show this static index.html page, but the interactive dashboard runs through Streamlit, not plain GitHub Pages.
